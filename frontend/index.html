Technical Specifications

Built for security professionals, by security professionals

📥 Input Formats

  • CSV exports from all major vendors
  • XLSX spreadsheet formats
  • Batch processing of multiple files
  • Auto-detection of vendor formats

🛡️ Risk Detection

  • Open administrative ports (SSH, RDP, Telnet)
  • Excessive allow-any rules
  • Overly broad source/destination ranges
  • Redundant and shadowed rules
  • Misconfigured inbound policies
  • Malformed or incomplete entries

  • Technical CSV with full rule details

  • Memory-efficient processing

About FireFind

Developed by Triskele Labs' Digital Forensics and Incident Response Team

FireFind was born from real-world incident response experiences where dangerous firewall configurations led to security breaches. Too often, organizations lack the tools to easily review firewall rules that have grown complex over time.

Existing solutions are typically vendor-specific or require costly third-party tools, limiting accessibility. FireFind bridges this gap with an open-source, vendor-agnostic approach that makes firewall auditing accessible to organizations of all sizes.

Built for security teams and auditors, FireFind provides repeatable, transparent rule analysis to help identify exposures and prioritize remediation across heterogeneous firewall environments.
