Configuration Console

Manage FireFind risk levels, CIDR limits, and reusable port groups with immediate validation aligned with backend rules.

Importing merges additional keys from the source file and preserves them for export.

Provide or import configuration to begin.

Risk Levels

Define severity labels and numeric thresholds used by the risk engine.

Severity options mirror backend enumeration (critical, high, medium, low, informational). Threshold minimums must not exceed maximums and negative finding counts are rejected.

CIDR Limit Sets

Specify default and override policies controlling allowed network breadth.

Prefixes must be between /0 and /128. Provide CIDR values such as 10.0.0.0/8 or 2001:db8::/32. Blocked and exempt entries accept newline or comma separated CIDRs and are validated using the backend parser rules.

Port Groups

Define reusable port groupings for analyzers.

Ports must be between 1 and 65535. Ranges cannot overlap or invert. Protocols follow backend expectations (tcp, udp, or any).
