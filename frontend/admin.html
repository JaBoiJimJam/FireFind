Risk Levels

Define severity labels and numeric thresholds used by the risk engine.

Severity options mirror backend enumeration (critical, high, medium, cautionary, low, informational). Threshold minimums must not exceed maximums and negative finding counts are rejected. Use the search filter above to quickly locate levels and the arrow controls on each card to reprioritize the evaluation order.

CIDR Limit Sets

Specify default and override policies controlling allowed network breadth.

Prefixes must be between /0 and /128. Provide CIDR values such as 10.0.0.0/8 or 2001:db8::/32. Blocked and exempt entries accept newline or comma separated CIDRs and are validated using the backend parser rules. Use the search filter to narrow large inventories and confirm before deleting a set to avoid losing tailored overrides.

Port Groups

Define reusable port groupings for analyzers.

Ports must be between 1 and 65535. Ranges cannot overlap or invert. Protocols follow backend expectations (tcp, udp, or any). The search filter helps locate existing groups and hovering action buttons reveals tooltips describing their purpose.

Rule Logic

Author analyzer rule definitions, including condition logic and analyzer overrides.

Conditions and analyzers accept YAML that maps directly to the backend schema. Provide a logic tree describing rule criteria and analyzer-specific metadata, including severity overrides and administrative port tiers. Use the search filter to explore existing logic, reorder cards to influence evaluation order, and rely on tooltips for clarification before toggling or deleting a rule.
